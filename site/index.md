# OMINOUS—FOR (J)IM: A Sentiment Analysis of the *Aeolus* Microtexts

The aim of this project is to explore the microtexts of the *Aeolus*
episode as social media content. The key research questions are:

**RQ1**: How is sentiment distributed across the text, according to
human, lexicon-based and LLM sentiment analysers?

**RQ2:** Is there a correlation between sentiment polarity/intensity and
nationalism in the episode?

**RQ3:** How much do the microtexts resemble contemporary social media
content? (Can an LLM be fooled into thinking the mirotexts are UGC?)
