# Index each line of Aeolus to a microtext

Index each line of Aeolus to a microtext

## Usage

``` r
index_microtexts(microtext_divider_col)
```

## Arguments

- microtext_divider_col:

  Logical column: T == headline; F == body

## Value

A vector, same length as `microtext_divider_col`, numbering microtexts
