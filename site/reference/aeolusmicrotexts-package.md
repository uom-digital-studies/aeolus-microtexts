# aeolusmicrotexts: Sentiment Analysis of the Aeolus Microtexts

Reproducible analysis code and data for a study of the microtexts
embedded in the "Aeolus" episode of James Joyce's Ulysses, treated as
social-media-like content. Provides functions to load and tokenise the
source text, run lexicon-based and LLM-based sentiment analysis, and
support related research questions on nationalism and resemblance to
user-generated content.
