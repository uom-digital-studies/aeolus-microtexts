# Install `aeolusmicrotexts` rather than `devtools::load_all()` for `targets`/`crew.cluster` workers

The `targets` pipeline (ADR 0001) needs `crew.cluster` SLURM workers to access `aeolusmicrotexts`'s functions. The existing hand-written CLI scripts (`ollama-*.R`, being retired) use `devtools::load_all(".")`, which is fast to iterate with but ties every run to whatever's on disk, including uncommitted changes. The `targets` manual is also explicit that `devtools::load_all()` does not make a package available to parallel workers at all — both of `tar_option_set()`'s package-tracking mechanisms (`packages`, `imports`) require a formally installed package.

We chose to fully install `aeolusmicrotexts` (`renv::install(".")` / `R CMD INSTALL`) everywhere the pipeline runs — dev machine, the Dockerised SLURM validation cluster, and the real HPC cluster — rather than `load_all()`. `tar_option_set()` sets both `packages = "aeolusmicrotexts"` (so `library()` runs before each target) and `imports = "aeolusmicrotexts"` (so `targets` hashes the installed package's function bodies for fine-grained cache invalidation, useful while the RQ schemas are still being revised). A small wrapper script reinstalls the package before every `tar_make()` so a stale install can't silently linger. `compute-node.Dockerfile` builds/installs the package the same way real HPC will, rather than just mounting source, so the Docker smoke test validates the actual deploy mechanism.

The trade-off accepted: a slower dev loop (edit → reinstall → `tar_make()`, instead of edit → `tar_make()`) in exchange for reproducibility — every run's `results/<run_id>/...` output (ADR 0003; see the "Run" entry in `CONTEXT.md`) is traceable to one pinned, installable package version, which matters because promoted results feed published research. This assumes compute nodes on the real HPC cluster share a filesystem/renv library with the submission node, mirroring what the existing `.slurm` script already implicitly assumes; unconfirmed on real hardware, to be revisited if it doesn't hold.
